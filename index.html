02二、我们收集哪些信息

我们不收集您的任何个人信息。

本游戏为完全离线的单机游戏，在运行过程中：

  • 不收集您的姓名、手机号、身份证号、邮箱等身份信息；
  • 不收集您的设备信息（IMEI、MAC 地址、Android ID、OAID 等）；
  • 不收集您的位置信息；
  • 不读取您的通讯录、短信、相册、摄像头、麦克风；
  • 不收集您的游戏行为数据用于分析、画像或推送。

因本游戏未申请网络访问权限（android.permission.INTERNET），技术上不具备向任何服务器传输数据的能力。

03三、权限使用说明

本游戏仅申请以下一项系统权限：

权限用途是否涉及隐私
android.permission.VIBRATE游戏内震动反馈效果否，不涉及任何个人信息

除此之外，本游戏未申请网络访问、设备识别、定位、通讯录、短信、摄像头、麦克风、存储读写等任何其他权限。

04四、本地数据存储

本游戏在您的设备本地保存以下数据，用于记录游戏进度：

数据存储方式用途
游戏存档（等级、装备、地图进度、设置项）浏览器本地存储（localStorage）下次启动时恢复游戏进度

上述数据：

  • 仅保存在您的设备本地，不会上传至任何服务器；
  • 我们不读取、不分析、不共享这些数据；
  • 您可通过清除应用数据或卸载应用完全删除这些数据。

05五、第三方 SDK 与共享

本游戏未接入任何第三方 SDK，包括但不限于：

  • 统计分析 SDK（如友盟、TalkingData、神策）
  • 广告 SDK（如穿山甲、优量汇）
  • 推送 SDK
  • 登录/支付 SDK
  • 崩溃上报 SDK

因此我们不会向任何第三方共享、转让或公开披露您的任何信息。

06六、未成年人保护

本游戏不收集任何个人信息，也不具备联网与付费功能，不存在诱导未成年人消费的情形。

我们建议未成年人在监护人指导下使用本游戏，并注意合理安排游戏时间。

07七、您的权利

由于我们不收集您的个人信息，您无需行使查询、更正、删除个人信息的权利。

如您希望清除本地游戏数据，可通过以下任一方式：

  1. 在设备「设置 → 应用 → 灰区撤离 → 存储」中清除数据；
  2. 卸载本游戏。

08八、信息安全

本游戏不含服务器端数据存储，不存在数据泄露、被窃取的风险。本地存档数据受您设备自身的安全机制保护。

09九、政策更新

如本政策发生变更，我们将在游戏更新说明及本页面同步更新，并在显著位置提示。若变更涉及个人信息处理方式的实质性变化，我们将重新征得您的同意。
